# Semana 1

Esta carpeta reúne las actividades correspondientes a la **Semana 1** de la asignatura **MCDI503 - Exploración Inteligente para la Ciencia de Datos**.

Durante esta etapa se establece la base metodológica del proyecto utilizando el dataset **Titanic**, abordando la definición inicial del problema, la caracterización del conjunto de datos y el desarrollo de una primera aproximación reproducible al análisis exploratorio de datos.

## Organización

La Semana 1 se compone de dos entregas:

- `MCDI503_F1_Formativa_Grupo6/`: evaluación formativa orientada a la definición del proyecto, caracterización inicial del dataset y planificación del análisis exploratorio.
- `MCDI503_F1_Sumativa_Grupo6/`: evaluación sumativa correspondiente a la implementación reproducible del análisis exploratorio inicial, incluyendo documentación técnica, transformaciones, visualizaciones y resultados.

## Continuidad del proyecto

Los resultados obtenidos durante esta semana constituyen la base para las etapas posteriores de preparación, calidad e integración de datos desarrolladas durante la Semana 2.

El proyecto mantiene continuidad sobre el mismo dataset **Titanic**, permitiendo conservar la trazabilidad de las decisiones metodológicas y técnicas a lo largo de las distintas fases del curso.
